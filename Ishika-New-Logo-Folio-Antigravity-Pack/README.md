# Ishika Shrivastav — New Logo Folio Integration Pack

This is the **NEW** six-brand concept collection. It replaces the old collection featuring solis, noka, FORMA, arc, kefi and COVE.

## Contents
- `public/projects/logo-folio/logo-folio-master.png` — unmodified generated editorial board
- `public/projects/logo-folio/logo-folio-overview.webp` — web-optimized complete overview
- `public/projects/logo-folio/logo-folio-homepage-cover.webp` — 16:9 cover with full artwork visible
- `public/projects/logo-folio/brands/` — 6 full cropped case-study panels from the original board
- `public/projects/logo-folio/previews/` — 6 hero preview crops
- `logo-folio.project.json` — project metadata with accurate paths and brand order
- `ANTIGRAVITY_ADD_LOGO_FOLIO.md` — integration prompt for existing website

## How to use
1. Unzip this folder and copy the **contents** of its `public/` into your existing site's `public/` folder.
2. Keep `logo-folio.project.json` at project root, or point Antigravity to its actual location.
3. Paste the markdown prompt into Antigravity after uploading the folder.
4. Ask Antigravity to verify the homepage card and project detail page in the browser.

## Accuracy note
These are fictional, AI-assisted graphic concept studies. They are **not** verified client commissions or hand-built editable logo vector files. The crop images and original board are pixel images. Some small type within AI imagery may be imperfect; review before public posting.
