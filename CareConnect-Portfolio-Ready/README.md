# CareConnect — Portfolio-ready assets

This is a curated, web-optimized export of the user-supplied `CareConnect.zip` for Ishika Shrivastav's design portfolio. It is not a modification of the original source archive.

## Files
- `public/projects/careconnect/cover.webp`: original 01 Welcome & Connect screen; recommended as the compact portrait project cover.
- `public/projects/careconnect/overview.webp`: all ten screens together; best for a full-width case study overview or landscape work card (use `object-fit: contain`).
- `public/projects/careconnect/style-guide.webp`: original project's mobile style guide.
- `public/projects/careconnect/gallery/`: ten actual screen exports in original sequence (web-optimized; visual content unchanged).
- `public/projects/careconnect/prototype/index.html`: self-contained offline interactive prototype, included as an optional demonstration link. Actions are simulated.
- `content/careconnect.json`: text, metadata, screen grouping and image paths.
- `ANTIGRAVITY_CARECONNECT_PROMPT.md`: exact prompt for integration prior to main build.

## Important distinction
The overall portfolio uses #890149, #F3F3E7, Cubao and Poppins. The **CareConnect project itself** uses its own iris #5146A6, warm white #FAF8F5, navy #25304A and Atkinson Hyperlegible Next. Do not alter its artwork to fit the portfolio branding.

## Scope and accuracy
The source includes 10 designed mobile screens, an interactive prototype, a style guide, vectors and Figma-import instructions. It is a design concept/prototype, not a working medication-management or emergency service. The source does not establish real-world impact, end-user testing or Ishika's specific design role.
