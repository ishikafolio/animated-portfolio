## Realism and motion quality
Motion must be intentional, art-directed and different in each section. Plan at least 3 frames per sequence and verify first and last frame transition into actual project assets. Intro animations should be <3s in normal-play mode. Keep chapter boundary perceptible but do not hard-lock the scroll.

## Video strategy
If user specifically wants **videos**, render actual MP4/WebM assets for each intro, using its title and authentic visual ingredients, and integrate them with fallback posters. For strong scrubbability and reversible scroll, prefer vector/SVG/GSAP implementation instead of seeking arbitrary MP4 time positions; the result should feel like a polished motion graphic. If only GSAP animations are built, label that truthfully as interactive motion graphics, not video files.

## 2.5D character rig
A still cutout alone supports basic translation, breathing and 3D CSS rotations, not true eye-following. For believable gaze, separate face + eyes/pupils with masking and a rig. For hair movement, segment front/back lock artwork or create an actual rig. If rig unavailable, deliver tasteful subtle motion and document limitation.
